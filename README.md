# Little Wings

A polished, responsive Flappy Bird–style game built with HTML, CSS, and the Canvas 2D API. No build step or JavaScript dependencies.

## Run

```sh
npm start
```

Open http://localhost:3000. Or open `index.html` directly in a browser. Google Fonts are optional; system font fallbacks are provided.

## Controls

- **Space / Up arrow / click / tap:** take off and flap
- **P:** pause or resume
- **R:** start a fresh flight
- **Speaker button:** toggle synthesized sound (off by default)

Pass a pipe to earn a point. Pipes get gradually faster. Your personal best is saved in this browser when local storage is available. Switching tabs pauses your flight; resizing the window starts a fresh ready screen.

## Check

```sh
npm run check
```
