# Phasmo 2D

A top-down 2D ghost-hunting game inspired by Phasmophobia, in a single HTML file with no dependencies.

Open `index.html` in a browser (or serve the folder with `python3 -m http.server`).

Grab tools from the truck, find three pieces of evidence in the house, pick the ghost type in the journal (J), and leave from the truck before the ghost hunts you down.
